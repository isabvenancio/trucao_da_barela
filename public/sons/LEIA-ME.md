# Sons do jogo

Coloque aqui os arquivos de áudio (`.mp3`, `.ogg` ou `.wav`, de preferência até 3 s) e aponte cada evento para o arquivo em `manifesto.json`:

```json
{ "doze": "doze.mp3" }
```

Evento com `null` ou arquivo ausente toca o som sintetizado de reserva.
Registre a origem e a licença de cada arquivo na seção de créditos do README (RNF-010).
